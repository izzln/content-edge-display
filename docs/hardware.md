# 嵌入式硬件选型

> **结论（已确认）**：采用 **Orange Pi One**（全志 H3，1GB）。部署步骤见 [deployment.md](deployment.md)。
> 以下对比保留作为决策记录，换型号时可直接复用这套判断。

## 1. 需求与约束

- HDMI 输出 1440×900（LCD 1440×900 + HDMI 驱动板；内核 `video=` 参数强制该模式，不依赖驱动板 EDID）；
- 以太网：**百兆即可**（H.264 码率仅数 Mbps，且是下载缓存不是实时流）；
- **不需要 PoE**：液晶面板本身需要独立供电，PoE 省不掉电源线；
- H.264 解码（1440×900 内硬解优先、软解可兜底）；能跑 Linux（Armbian）；
- 小批量采购。

## 3. 判断依据

- 成本视角：主板低于 ¥60 后已不是成本大头——电源、工业级 SD 卡、外壳、**一次现场维护的人工成本**
  都超过省下的差价。"更贵但更稳"在总拥有成本上往往更便宜；
- 二手盒子自带 eMMC，比 SD 卡更抗掉卡，但货源批次不一、需逐台刷机验机，适合验证期或能接受折腾的场景；
- **软件路线统一**：Armbian/Debian + mpv + 自研轻量代理。全部候选硬件共用同一套软件栈，
  后期换硬件**不用改代码**，只需换一次交叉编译目标；
- 若后期量产，可评估**广告机一体主板直驱 LCD（LVDS/eDP）**，去掉"HDMI 驱动板"一层，
  整机 BOM 与故障点都更少。

## 4. 附：二手 S905L3A 盒子刷 Armbian 指南

以最常见的中国移动魔百盒 **M401A / UNT403A**（S905L3A）为例，使用 ophub 的
[amlogic-s9xxx-armbian](https://github.com/ophub/amlogic-s9xxx-armbian) 固件。

1. **选购**
   - 闲鱼按型号采购**同批次**（M401A 最经典、资料最全）；
   - 也可直接买标明"已刷 Armbian / 已开启 U 盘启动"的成品，溢价约 ¥10–20，省去逐台折腾。
2. **下载镜像**：在 ophub Releases 中选择 `s905l3a` 对应镜像（形如 `Armbian_..._amlogic_s905l3a_*.img.gz`）。
3. **写 U 盘**
   - 用 balenaEtcher / Rufus 将镜像写入 U 盘；
   - 编辑 U 盘 `/boot/uEnv.txt`，将 `FDT` 行指向对应 dtb（如 `meson-g12a-s905l3a-m401a.dtb`）。
4. **U 盘启动**
   - 盒子断电、插入 U 盘；
   - 牙签按住盒内 reset 键（部分型号藏在 AV 孔内）同时上电，保持约 5 秒；
   - 成功后从 U 盘引导进入 Armbian（默认账号 `root` / `1234`）。
5. **写入 eMMC**
   - 在 U 盘系统内运行 `armbian-install`，选择对应机型/dtb；
   - 完成后关机、拔 U 盘、重新上电，即从 eMMC 运行。
6. **避坑与验机**
   - 部分新批次盒子**锁了 bootloader**（如某些 E900V22C），需拆机短接用 USB Burning Tool
     线刷解锁底包——采购时避开，认准 M401A/UNT403A 等易刷型号；
   - 每台刷完跑一遍验机清单（见 [deployment.md](deployment.md) 第 6 节），另加：
     CPU 型号 `cat /proc/cpuinfo`、内存容量、mpv 硬解播放测试片。
