显示屏管理后台

全局默认模板
没有专属模板的设备都显示它。属性在左还是在右，用设备"内容"里的左右对调切换；图片停留时长写在模板里。

统一作用于所有设备：保存后在线设备一个轮询周期内生效，离线设备上线即生效。

程序更新

程序包与离线依赖包都从这里上传，按内容自动区分。 程序包：make package 产出的 display-agent-<版本>-armv7.tar.gz，版本号从包里读取，传错文件会被当场拒绝； 只保留一个，上传新版本即替换旧版本，还在等待更新的设备改为更新到新版本。 离线依赖包：make deps 产出的 display-deps-<代号>-armhf.tar.gz，上传一次，之后装机与 OTA 新增的依赖都从这里装、不访问外网。

离线依赖包 设备的 Debian 版本代号（/etc/os-release）与之一致时，装机与 OTA 都从这里装依赖；否则在线安装

设备访问

    

      
root 密码

      
现场插键盘登录控制台用（配了 SSH 公钥后也只用于控制台）。服务端只存哈希；密码泄露、人员变动时重设。

      

         

    

    

      
SSH 公钥

      
每行一个，整行复制运维电脑上的 ~/.ssh/id_ed25519.pub。配了公钥后设备只允许密钥 SSH；
        设备上的 authorized_keys 每次整份按这里重写，增删、更换公钥随时保存即可；清空则恢复密码 SSH。
